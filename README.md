# SeatSense: Library & Study Room Finder

**Live demo:** _add your GitHub Pages link here_

## The problem
Students walk to the library only to find every seat taken, or spend ages hunting for a spot in the right zone.

## The solution
SeatSense shows the library floor as a live seat map so you can pick a seat before you leave your room.
- Seat map with free, taken and your own seats
- Quiet zone and group zone filters
- Live "how full is it right now" meter
- Reserve a seat for 30 minutes, 1 hour or 2 hours, with a live countdown and a release button
- "Best time to visit" chart with a suggestion for the quietest hour left today
- Demo speed switch so the countdown can be shown in a minute

## Tech stack
HTML, CSS and vanilla JavaScript in a single file. Other students' seats are simulated, and your reservation is saved in the browser with `localStorage`. No install, no backend.

## Run it locally
Open `index.html` in any browser.

## Built with AI
Designed and built with Claude using prompt-driven development. See `PROMPTS.md`.

## Future scope
Real occupancy from QR check-ins or sensors, room booking for study groups, and reminders before a reservation ends.
